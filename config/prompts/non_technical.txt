### 2. WHAT IS SQL INJECTION? (Business Context)
Explain SQL injection in simple terms:

SQL injection (SQLi) is a critical security vulnerability that allows attackers to manipulate database queries through web application inputs. When an application fails to properly validate user input, attackers can insert malicious code that tricks the database into revealing sensitive information, modifying data, or bypassing security controls.

**Real-World Example:**
Imagine a login form where an attacker types `admin' OR '1'='1` instead of a legitimate username. If the application is vulnerable, this can bypass password checks and grant unauthorized access to the system.
